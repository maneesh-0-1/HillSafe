# Hill Safe — Drone-Based Site Intelligence

An immersive 3D scrolltelling web experience for **Hill Safe**, showcasing next-generation autonomous drone-based spatial capture and terrain intelligence.

Physical World → Capture → Data → 3D → Analysis → Intelligence

---

## 🚀 Features

- **3D Spatial Visualization**: Built with Three.js and `@react-three/fiber` / `@react-three/drei`.
- **Cinematic Scrolltelling**: Smooth narrative progression powered by Lenis and GSAP.
- **Analytical Layers**: Interactive inspection overlays for Elevation, Slope Risk, Water Flow, and Volumetric Surveying.
- **Responsive & Modern UI**: Built with Next.js 14 (App Router) and Tailwind CSS.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/)
- **3D Engine**: [Three.js](https://threejs.org/) & [React Three Fiber](https://r3f.docs.pmnd.rs/)
- **Scroll & Animations**: [Lenis](https://lenis.darkroom.engineering/) & [GSAP](https://greensock.com/gsap/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/maneesh-0-1/HillSafe.git
cd HillSafe
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

---

## 📦 Build for Production

```bash
npm run build
npm run start
```
