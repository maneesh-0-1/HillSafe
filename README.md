# HillSafe - Interactive 3D Drone Flight Experience

An interactive 3D drone flight simulation and site intelligence platform built with **Three.js** and **Vite**.

## Features

- **Physics-Based Flight**: Realistic drone flight dynamics with keyboard and UI controls.
- **Procedural 3D Terrain**: Dynamic topographic generation, contours, and environmental effects.
- **Spatial Audio**: Ambient engine sounds and realistic audio effects.
- **HUD & Telemetry**: Altitude, speed, battery, and coordinate instruments.

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
